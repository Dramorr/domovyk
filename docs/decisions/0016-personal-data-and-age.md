# 0016 — Персональні дані, вік 18+ і аватар

- Статус: **прийнято**
- Дата: 2026-11-09
- Автор: Олег
- Зачіпає: SPEC FR-USR-3; `users` (legal_name, birth_date, city_code, avatar_key); BOT_FLOWS PROF-1; API `/me/personal`, `/me/avatar`, `/users/{id}/avatar`

## Контекст

Профіль мав лише ім'я та «анкету орендаря» (тварини, діти, куріння). Анкета на рівні людини втратила сенс: в однієї людини може бути кілька оренд, а умови в кожній квартирі свої. Натомість для договору потрібні ПІБ і вік сторін, а для довіри — фото профілю.

Повна цивільна дієздатність в Україні — з 18 років (ЦКУ ст. 34); у 14–17 договори укладаються лише за згодою батьків. Домовик таких випадків не підтримує.

## Рішення

1. **Персональні дані** (бачить лише сама людина): ПІБ як у документах, дата народження, місто з довідника `cities`, підтверджений номер телефону (лише показ).
2. **18+.** Дату народження людина вносить сама; молодше `USER_MIN_AGE` (18, у конфігурації) зберегти не можна (`too_young`). Іншій стороні оренди показуємо **лише вік і лише на етапі договору** — він однаково потрапляє в договір.
3. **Аватар** — фото профілю (зменшене, без EXIF, як фото об'єктів), бачать усі зареєстровані користувачі. Файл у сховищі, у базі — ключ і час оновлення (версія для кешу).
4. **Анкета орендаря** з інтерфейсу прибрана; таблиця й API лишаються (умови житла — в оренді й оголошенні).
5. **Пароля немає**: вхід через Telegram. Пароль з'явиться разом із сайтом чи мобільним застосунком.
6. Видалення акаунта стирає персональні дані й аватар (FR-USR-5).

## Доповнення: дата народження — на реєстрації

Mini App питає дату народження одразу при реєстрації (ONB-2, під іменем) — без неї й молодшим 18 акаунт не створюється. Користувачі, що зареєструвалися раніше, вносять її в профілі; обов'язковість для старих акаунтів перед орендою й вік сторін у договорі — разом із доопрацюванням договору (M4).

## Наслідки

- У договорі є звідки взяти ПІБ і вік без повторного вводу.
- Більше персональних даних у базі — лише необхідні; телефон і ПІБ іншим не видно.
