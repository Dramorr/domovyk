# Безпека

Знайшов вразливість? **Не відкривай публічний issue.** Напиши через
[приватне повідомлення про вразливість](../../security/advisories/new) на GitHub.
Відповімо протягом кількох днів.

## Що ніколи не потрапляє в репозиторій

- Токени, ключі, паролі — лише в `.env` (у `.gitignore`), шаблон — `.env.example`.
- Документи користувачів: довідки ДРРП, квитанції, файли підписів, дампи бази.

Захист: `.gitignore`, gitleaks у CI і в pre-commit, GitHub secret scanning з push protection.
Якщо секрет усе ж потрапив у коміт — **одразу відклич і перевипусти його** (видалення з історії не допомагає, бо копії вже могли зробити).
